# Algorithmus Inkrementelles Zählverfahren zur Erzeugung von Primzahlen – Dokumentation (Deutsch)

Dieses Verzeichnis enthält die vollständige deutschsprachige Beschreibung des
Algorithmus "Inkrementelles Zählverfahren zur Erzeugung von Primzahlen". Das Dokument erläutert die mathematischen
Grundlagen, die Struktur des Algorithmus sowie ein kleines Beispiel.
